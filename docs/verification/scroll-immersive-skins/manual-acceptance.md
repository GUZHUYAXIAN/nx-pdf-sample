# 2.1.0 整体滚动与融合皮肤人工验收

状态为待验。使用新候选 ZIP 或同一候选目录中的 `clean extraction`，启动 `NX图纸批量导出工具.exe`，同时保留 `worker`、`assets`、`en`。记录 ZIP SHA-256、Windows 缩放比例、窗口尺寸与 NX 版本。使用隔离的制图 PRT 和关联模型副本。

## 主体与两处高度

在 Windows 100%、125%、150% 下各执行一次。覆盖最小窗口和最大化。若有第二块不同缩放比例的屏幕，再测跨屏移动及 200%。

1. 展开设置，添加多个源目录。把指针停在标题、设置输入框和空白区，滚轮应带动主体。设置末尾接预检查工具栏。菜单和底部开始、取消、状态、进度固定。
2. 手动清单、预检查和结果分别用 0 行、少量行和多行检查。放得下时，表内纵向条应消失，滚轮滚主体。出现溢出时，指针所在表先滚，表内到顶或到底后下一次滚轮接着滚主体。触控板小幅连滚时不应同时移动内外两层。打开 NX 下拉选项后滚轮应继续操作下拉。
3. 增加长中文名、空格和长无空格文件名。检查完整换行、列宽拖动、横向条按需出现，以及横条占空间时纵向条只在需要时出现。快速缩放窗口，检查滚动条是否反复闪现。
4. 拖动预检查表下方手柄，向下增高。拖动结果标题和列头之间的手柄，向上增高。两表高度互相独立，底部操作保持固定。用 Tab 聚焦手柄后测试方向键，拖动时将鼠标移出手柄再松开。
5. 重启检查两个高度是否保留。执行恢复布局，核对两处高度和列宽回到默认值。操作前后核对已选文件、目录映射和版次。
6. 在预检查用 F2 或双击进入版次，输入未确认的 R100 和一组无效文字。滚动、拖高手柄、折叠设置、切换主题与语言后核对编辑器和已选行。测试中文输入法组合、剪贴板、Esc、Enter、筛选、多选和批量版次。点击开始时应按原规则校验并冻结版次。

## 融合皮肤与预览

1. 逐个启用蕾姆、楪祈、芙莉莲、洛琪希。检查右侧空间用于工作内容，菜单、设置、三个表格、输出目录行和底部连用同一张固定底图。
2. 滚动主体和各表，拖高手柄、调整窗宽。检查照片接缝、白底闪现和文字跳色。验证表头、空表、普通/悬停/多选/焦点状态、版次编辑器、滚动条、菜单、提示与详情对话框。
3. 用两组 PRT 检查清单和输出设置中的组色及 A/B 标识。选中行时仍能辨认组别。用成功、跳过、失败结果检查状态标签和图标。
4. 分别导入纯白、纯黑、黑白条纹、高纹理、带透明区的 PNG 和竖构图图像。核对正文、文件名、路径和状态在亮暗区域清楚，滚动时字色稳定。
5. 分别改图片强度、面板遮罩、模糊、雾化、渐变强度与四个方向、缩放和位置。切换深浅融合与手动字色，核对保护提示和滑杆原值。恢复自动，再恢复当前预设，检查其他预设的调整值。
6. 快速切图、滑动效果后立刻取消。等待后台任务结束，核对原图、配色、遮罩和导入槽已恢复。应用后重启检查保存结果。试坏图、缺失图和超限图，确认当前有效外观可用。
7. 逐个检查五套纯色主题。在 Windows 高对比模式进入和退出后核对系统色与图片皮肤恢复。测试导出进行中切换外观和取消操作。

每档保存全窗截图，另保存预检查编辑、两个高度手柄和亮暗混合图三个局部。记录触发步骤和当时皮肤参数。可用短录屏记录边界滚动或预览取消，便于确认是否跳色、跳位置。

## 断网与 NX

断网前分别计算隔离制图和关联模型的 SHA-256。断开物理网络后启动新候选，加载一个内置皮肤、一个本地图和两种语言。用所选 NX 串行导出一份制图，检查 PDF 结构、图幅和标注。复算两个源文件的 SHA-256 后再恢复网络。两代 NX 要分别验证。对于 NX 2506 打开的旧图纸，额外对照原始 NX 版本和参考 PDF 的角度与尺寸标注。其他电脑、物理断网和本轮真实 NX 证据分别记录。
