# 2.1.0 整体滚动与融合皮肤候选验证

本轮候选从上轮 2.1.0 和本轮已批准设计继续实施。新包目录为 `artifacts/release/scroll-immersive-skins-candidate-20261112`。原候选仍位于自己的目录。包内 `build-info.txt` 记录实际构建提交，包外 `candidate.sha256` 与 `manifest.sha256` 分别记录 ZIP 和文件校验值。

| 验证项 | 范围 |
|---|---|
| 配置、滚轮规则与高度 | App 测试覆盖 schema 1/2、损坏字段、独立高度、DPI、行高溢出、方向边界和小滚轮增量。 |
| 自动配色与保护 | App 测试覆盖 sRGB 阈值、单像素亮斑、混合背景、手动灰色、组/选中材料及四张实际预置图的离屏计算。测试按缓存像素的保守颜色边界求最差对比度。 |
| 缓存与预览 | App 测试覆盖固定坐标映射、恢复请求后的迟到帧淘汰、关闭期间迟到帧释放和应用前草稿隔离。 |
| Release 测试、构建和解压 | 以 `artifacts/scroll-immersive-skins-candidate-20261112.log` 的实际退出码和包清单结果为准。 |
| 真实 WinForms、DPI、实体断网 | 待用户按[验收清单](manual-acceptance.md)完成。对比算法测试与包完整性检查不构成桌面视觉或输入法验收。 |
| 真实 NX、PDF 和源文件哈希 | 本轮未重跑真实 NX。Core、Contracts、两代 Worker 和导出控制器属于上轮已验证路径。上轮候选在本机的两代 Worker/PDF/源哈希记录仍见 [2.1.0 验证记录](../ui-revision-skins/README.md)。NX 2506 的旧图纸角度和尺寸标注视觉差异继续保留为已知限制。 |

主体采用 WinForms 标准滚动区域。表格保留 DataGridView、原生编辑器和原生滚动条的输入机制，图片模式采用自有绘制。系统高对比模式恢复原生配色与滚动条外观。预设和导入图都在应用本地处理。

字色按当前照片及效果计算并缓存。文字所在的材料会为最差位置增强保护，个别强反差区域的图像显现程度可能降低。手动遮罩参数仍按用户请求值保存。schema 2 使用两个高度，旧单一分隔比例迁移为 280/320 DIP；旧版应用不识别 schema 2。
