# 2.1.0 本地候选人工验收

当前状态为待验。使用同一份候选 ZIP，记录其 SHA-256、Windows 版本、分辨率和实际 NX 组件版本。制图与关联模型使用同目录的隔离副本。保留截图、日志和哈希在本地。

## GUI 与 DPI

在 Windows 设置中分别选择 **100%、125%、150%** 缩放。每档重新启动候选并保存 Windows 缩放设置与应用窗口截图。

| 步骤 | 核对内容 |
|---|---|
| 启动并选择 NX | 中文默认，NX 状态和路径可读。双安装无有效保存选择时，需明确选择一套。 |
| 调整窗口与分隔条 | 在最小和最大窗口拖动预检查与结果的水平分隔条。开始、取消和进度始终可见。上方设置可滚动和折叠，折叠后仍能看到 NX、文件数量和输出方式。重启核对窗口、分隔比例和列宽。 |
| 扫描和手动清单 | 扫描默认折叠。单独展开手动清单时模式保持扫描、清单只读。选手动自动展开，折叠不清空已选文件。 |
| 长文件名与路径 | 使用含长中文、空格和多点号的 PRT 名。拖动源和目标列的列边界。完整名称可换行，悬停可见完整路径。双击普通单元格查看详情，双击版次进入编辑。 |
| 分组与输出 | 递归扫描或选两个不同完整目录里的 PRT，核对序号、组号和底纹与输出行对应。修改一组、浏览取消、恢复源目录，分别核对其他组值。切换统一输出应只显示一行，切回应保留组映射。 |
| 预检查与版次 | 检查 0、R2、R100、非法输入和已有目标。按搜索或问题过滤后选中可见行，再批量改版次或恢复建议，确认隐藏行未被修改。刷新与完成一轮导出后重新检查，手动值仍保留。 |
| 键盘与双语 | 用 Tab、F2、Enter、Esc 和 F4 检查导航、编辑和详情。输入合法版次后切换语言或主题，再确认目标名。完成导出后切换 English，核对菜单、状态、原因和汇总。打开选中项所在目录应对应当前选择。 |
| 结果和取消 | 在隔离任务中取消，核对已经完成的条目、尚未执行的条目和实际目标目录。失败原因与日志能够对应。 |

每档记录窗口状态、触发操作、预期及实际。若出现裁切、重叠、开始/取消不可见或状态无法读取，保留现场后提交问题。

## 主题与图片

1. 逐个应用云白、石墨黑、湖蓝、松绿和暖砂，核对文字、编辑器、选中态、组标识和焦点。
2. 逐个选择蕾姆、楪祈、芙莉莲和洛琪希，核对缩略图、角色可辨识、裁切与表格可读性。
3. 在同一预设上分别调节显现程度、缩放、水平/垂直位置、模糊、雾化和渐变。显现程度 0 时图片隐藏，模糊/雾化/渐变 0 时对应效果关闭。
4. 取消应回到打开面板前的外观。应用后重启应恢复效果。恢复当前预设只重置该套参数。
5. 导入有效 PNG/JPEG 后核对原图 SHA-256，再试坏图、超过 32 MiB 的文件和超过 4096 万像素的图片。确认导出工作区仍可用。

## 物理断网与干净解压

1. 把 ZIP 解压到仓库外的全新路径。保留 EXE、`worker`、`assets/themes` 和 `en`。核对 ZIP 的 SHA-256。
2. 在两份副本上执行 `Get-FileHash -Algorithm SHA256 -LiteralPath <文件>`，分别记录制图 PRT 和关联模型。
3. 关闭 Wi‑Fi、拔掉网线或禁用当前网络适配器。启动程序，切换语言和一套角色皮肤，确认本地资源可加载。
4. 选择有效 NX，按分组模式导出到隔离的输出目录。核对 PDF 页数、图幅、主要标注和日志。检查运行中有无联网、更新或认证提示。
5. 复算两份 PRT 的 SHA-256。任何变化、正式输出残缺、启动器错误或联网提示均记录为失败，保留现场后恢复网络。
6. 在另一台 Windows 11 x64 机器上重复，记录安装目录来源和精确版本。优先使用一份由 NX 2506 原生创建的制图验证其标注输出。

历史旧图纸在 NX 2506 上的标注显示差异仍需核对。若人工参考与导出不一致，保留两份 PDF、标注位置和所选 NX 版本。
