# 2.1.0 界面、分组和升版本地候选验证

验证日期为 2026-11-12，范围为活动 V2 工作树和本机两套已验证 NX 安装。

| 项目 | 状态与证据 |
|---|---|
| 自动化及 Release 构建 | 候选脚本使用既有 SDK 10.0.400 和本地包缓存执行。详细计数及警告以最终打包日志为准。 |
| NX 10.0.0.24 与 NX 2506 | 依次通过真实 Session、UFSession 和程序集来源校验。各完成四次运行，覆盖两个源目录各自映射、0 版、新增 R101、手动覆盖 0 版和取消。 |
| 源文件保护 | 每次运行分别记录原始制图、模型和两组隔离副本前后 SHA-256。全部相同。私有样例路径和哈希记录仅保存在本地 artifacts。 |
| PDF 结构和视觉 | 两代各导出五份单页 A2 PDF，页尺寸 1683.78 × 1190.55 pt，使用系统 PDF 组件按 150 dpi 全部渲染。每代五张渲染图的 SHA-256 各自相同，逐代查看并与参考图比较。NX 10 的图框、视图和主要标注与参考一致。NX 2506 保留已观察到的角度及尺寸标注外观差异，视觉等价未通过。 |
| 角色插画 | 4 张生成式全分辨率插画与 4 张缩略图，附预设参数和来源声明。确认了角色、构图和画面完整性。应用中的显示、DPI 和效果组合由用户验收。 |
| GUI、DPI、物理断网和其他电脑 | 待验。使用[人工验收清单](manual-acceptance.md)。 |

真实运行由 `tools/verify-ui-revision-nx.ps1` 和同源无界面驱动执行。每个场景保存结构化结果、Worker stdout、前后哈希、PDF 检查 JSON 和逐页渲染。候选解压和 Worker 复验不代表已启动或操作 WinForms GUI。
