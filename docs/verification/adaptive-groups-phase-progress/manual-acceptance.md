# 2.1.0 人工验收清单

以下项目均待验。使用候选目录的 `clean extraction`，打开 `NX图纸批量导出工具.exe`，保留两套 Worker、英文资源和素材。导出测试使用图纸与关联模型的受控副本，正式输出指向独立测试目录。

## 四处组色

- [ ] 先选两个实际父目录各一份图纸。在按组输出模式下，同一目录在手动清单、预检查、运行结果和输出目录的整行使用同一组色，A/B 标签与组列色块清楚，统一输出设置可以切回。
- [ ] 用六组及八组复验。六组时能看出相邻行的归属，第七、八组与先前各组可辨。新增组、改变排序、筛选、滚动、调整表格高度后，原有各组的色相及标签保持稳定。
- [ ] 保留上一次结果，改变当前输入再预检查。旧结果仍显示原目录的组色。用不同目录对应同标签的场景时，组色按目录识别。
- [ ] 逐项选中、悬停和多选，编辑预检查版次，调整输出目录。组列色块和文字可辨，状态文字保护只占自身范围。长中文路径可换行，原来的焦点、选区和滚轮转交可用。

## 外观和配置

- [ ] 在四张预置图、纯色主题和一张本地导入图中查看。用高反差或带亮斑的图对比自动、深、浅模式。深浅切换保留组色身份，换图可调整配色。滑动或缩放窗口时字色不跳变。
- [ ] 在照片与纯色下依次试分组颜色强度 0、65、100。0 关闭整行组色并保留组标记，65 明显，100 仍可读。照片、面板和手动字色控件保存原输入值。
- [ ] 改图和强度后取消，确认之前的图、强度和各组身份恢复。再缩放或加入新组复核。应用后重开确认配置持久化，并检查其他皮肤的单独设置。
- [ ] 查看系统高对比模式、五种纯色主题、中英切换。核对窗口布局、表格内部滚动和各自高度手柄仍可用。

## 真实导出和安全保存

- [ ] 用多份受控图纸运行。导出阶段显示当前序号、文件名、实际子步骤和已处理/已生成数。可悬停文件细节查看路径。跳过已有 PDF 的项目排除在导出分母之外。
- [ ] 观察条纹活动段只占一份文件。若 32 份中已处理 10 份且正在处理第 11 份，应显示 31.25%，实色占 10/32，条纹占 1/32，余量保持底色。按相同公式核对实际分母。
- [ ] 观察切换到“校验并保存”，标题和分母同时切换。保存分母来自可信结果中的临时成功项。临时文件验证失败不增加已保存数。覆盖数量包含在已保存内。只跳过和零可保存项显示专用文案。
- [ ] 分别在准备、真实导出和校验并保存阶段点取消。准备期在安全边界收尾且不开始 NX 文件。导出期已完成成果仍经过验证后保存，未执行余项不计已处理。保存期当前安全发布完成后停止其余候选。按钮反馈及时，重新开始后计数清零。
- [ ] 用 NX 10 和 NX 2506 分别查看现有 0 版、指定覆盖、建议新版本、重做预检查和结果详情。用临时输出测试目标冲突，核对旧 PDF 在新文件有效前保留。

## DPI 和物理断网

- [ ] 在 100%、125%、150% DPI 下用最小可用窗口截图。至少记录深浅各一套组色，以及导出和保存两阶段。核对固定底部、条纹图例、换行后的文件名、表头、版次编辑框及滚动条。
- [ ] 物理断网后从干净解压目录启动。切换纯色和角色皮肤，导入本地图，运行受控副本并检查正式 PDF。记录 NX 所使用的许可证方式与两阶段行为。另一台机器的验收单独记录。
