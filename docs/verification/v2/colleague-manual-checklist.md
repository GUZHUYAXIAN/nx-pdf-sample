# V2 同事电脑人工操作与截图清单

本清单与 `docs/prompts/2026-09-08-colleague-v2-validation-prompt.md` 配套。所有界面
操作由测试人员本人完成，Codex 只运行只读命令并整理证据。

## 前置条件

- Windows 11 x64。
- 已安装 Siemens NX 10.0.0.24；不得为了测试移动或重装 NX。
- 收到同一份冻结候选包和 SHA-256 manifest。
- 准备一组可安全读取的制图 PRT 与关联模型；两者不得被修改。
- 关闭其他可能编辑这两个 PRT 的 NX 会话。
- 准备仓库外的全新解压目录和独立输出目录。

## A. 异路径自动发现

1. 让 Codex 完成候选包 manifest、NX 文件存在性与 NXOpen.dll `10.0.0.24` 只读检查。
2. 由本人启动候选包中的 `NX图纸批量导出工具.exe`。
3. 不点击“手动选择 NX 目录”，等待自动检测结束。
4. 核对 NX 环境区显示的路径属于本机真实 NX 安装，版本为 `10.0.0.24`。
5. 截图：完整应用窗口，必须同时看到 NX 环境区、检测状态、根目录和版本。

若存在多个有效安装，确认后候选下拉框应继续可见，条目应同时显示根目录和版本；
仅高亮另一项不改变当前安装，点击“使用所选 NX”才切换。保存期间不允许再次
切换、刷新或开始导出。保存前后各留一张完整环境区截图；没有多安装条件则如实
标记该项 NOT RUN，不修改注册表或环境变量来制造条件。

预期结果：自动进入“已就绪”，“开始导出”可在输入有效后启用。若显示错误目录、
版本不符、一直检测或需要先手选，立即停止自动发现测试并保存截图和日志。

## B. 手动兜底（仅在记录自动发现结果后测试）

1. 点击“手动选择 NX 目录”。
2. 选择包含 `UGII` 文件夹的 NX 根目录，而不是 `UGII` 文件夹本身。
3. 核对验证结果和版本。
4. 截图：完整应用窗口与手动选择后的 NX 环境区。

预期结果：正确根目录通过；错误目录或其他 NX 版本被拒绝且不能启动 Worker。
手动通过不能替代 A 部分的自动发现证据。

## C. 真实导出

1. 在 Codex 记录两个 PRT 的运行前 SHA-256 后，选择制图 PRT。
2. 选择独立输出目录；第一次测试使用“跳过已有 PDF”，保证目标不存在。
3. 点击“执行预检查”，核对源文件、目标 PDF 和状态。
4. 截图：完整预检查区域和 NX 环境区。
5. 点击“开始导出”，等待终态，不关闭程序、不强行结束 NX Worker。
6. 截图：完整进度/结果区域、汇总和 NX 环境区。
7. 若 NX 弹出保存源 PRT、缺失依赖或其他异常提示，立即停止并截图。

预期结果：只启动一个顺序 Worker；正式 PDF 在校验后出现；结果为成功且没有残留
`.tmp.pdf`。随后由 Codex检查 result.json、PDF 和运行后 SHA-256。

## D. DPI 截图矩阵

分别在 Windows 100%、125%、150% 缩放下执行。每次更改缩放后按 Windows 提示
注销/重新登录或重新启动应用，确认缩放已经生效。

每档必须截图：

1. Windows 显示设置中的当前缩放值；
2. NX 自动检测成功的完整主窗口；
3. 扫描文件夹模式；
4. 手动多选 PRT 模式；
5. 统一输出目录中的长路径；
6. 预检查列表；
7. 导出运行中按钮禁用状态；
8. 最终结果列表与汇总。

逐图检查中文截断、重叠、裁切、不可访问按钮、列表宽高、长路径、滚动、Tab 顺序
和禁用状态。任一档出现缺陷就停止该档测试，保留缩放值与触发状态，不继续登记为
通过。

## E. 物理断网

此部分可以与 C 部分合并，但必须使用同一冻结候选包并重新计算运行前哈希。

1. 由本人关闭 Wi-Fi、断开网线或禁用当前网络适配器。
2. 截图：Windows 网络断开状态；避免显示无关网络名称或凭据。
3. 启动干净解压的程序，等待 NX 自动检测，执行一次受控导出。
4. 截图：断网状态下的 NX 就绪窗口和最终结果。
5. 确认没有联网、下载、更新或认证提示。
6. 等 Codex 完成 PDF 与运行后哈希检查并保存证据后，再恢复网络。

## 硬停止条件

- 候选包/manifest 哈希不一致；
- NXOpen.dll 不是 `10.0.0.24`；
- 自动发现选择错误安装；
- 要求管理员权限、安装工具或修改 NX/系统配置；
- 出现源 PRT 保存提示或任一源文件前后哈希不一致；
- 正式 PDF 缺失、为空、页数错误或存在残缺临时文件；
- 出现网络访问、下载、更新或认证行为；
- GUI 在任一缩放下发生裁切、重叠或无法操作。

触发停止条件后不要重复尝试或自行修复环境。保留候选包哈希、脱敏日志、对应截图
和失败阶段，交回项目开发者分析。
