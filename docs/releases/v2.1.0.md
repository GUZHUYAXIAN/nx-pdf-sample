## 相对 v2.0.1 的变化

- 可按 PRT 父目录分组输出，也可统一输出。预检查支持文件名搜索、问题筛选、批量指定数字版次和恢复建议版次。0 版保留原名，正数版次追加 `-R数字`。
- 设置、预检查和结果共用主体滚动区。预检查与结果表各有高度手柄。手动清单、预检查、结果和输出目录共用按源目录分配的组色，外观设置可调组色强度。
- 支持简体中文和 English、五种纯色主题、四张预置角色插画及本地图片导入。照片主题在本地分析画面并保护文字对比度。修复纯色和无底图时下拉框空白，以及照片主题放大字号时选项裁切的问题。[角色素材来源](../../src/NxDrawingPdfExporter.App/Assets/Themes/SOURCES.txt)
- 批处理先显示 NX 当前文件和实际子步骤，再显示校验并保存的进度。两个阶段使用各自的文件总数。进度快照仅供显示。正式保存逐项复核可信终态结果、冻结目标及临时 PDF。导出阶段取消后，已经完成的文件仍进入校验保存。保存阶段取消会在当前文件完成后收尾。

## 兼容与使用

Windows 11 x64。支持 README 列出的 NX 10 与 NX 2506 精确组件版本。GUI 与两套 Worker 使用同一个便携包，任务和结果采用协议 2。核对 ZIP 的 SHA-256 后完整解压至新目录，保留 `worker/nx10`、`worker/nx2506`、`en` 和 `assets`。对旧图纸使用制图与关联模型的副本验收，确认输出目标与版次后再开始。源 PRT 仅打开读取。

## 验证范围

- r3 的 Release 配置通过 308 项自动化测试，构建零错误。Worker 测试项目仍有既有的 NU1702 目标框架兼容警告。干净解压后逐项核对 27 个文件。候选包对应源码提交 `248bd79`。
- NX 10.0.0.24 与 NX 2506 各通过 4 个真实受控场景，覆盖双组输出、自动新建 R101、指定覆盖 0 版及导出取消。两代均捕获中间进度，8 次运行的图纸及模型 SHA-256 前后一致。
- 10 份单页 A2 PDF 的渲染与此前人工核对的对应图像逐字节一致。NX 2506 处理测试旧图时仍有角度和尺寸标注外观差异。
- 维护者已反馈试用满意。100%／125%／150% DPI 截图、物理断网和其他电脑的逐项验收仍待记录。[验证记录](../verification/adaptive-groups-phase-progress/README.md) · [人工验收清单](../verification/adaptive-groups-phase-progress/manual-acceptance.md)
