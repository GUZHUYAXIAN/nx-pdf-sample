# v2.0.1 — UG 10 / UG 2506 双版本更新

日期：2026-09-19。维护者手动试用当前版本后确认问题修复，并明确授权提交源码、推送及创建 GitHub Release。本记录作为本次发布的范围说明，不改写历史验证记录。

## 更新内容

- 自动发现 NX 10 和 NX 2506，支持明确选择、手动指定及记住有效安装；开始前重新核对安装身份。
- 一套便携 GUI 配合两套独立 Worker，各自使用相应 NX 启动器和组件。
- 子进程单独设置 NX 路径，隔离其他版本的路径及初始化覆盖，保留许可证、语言和编码设置；不改系统/NX 配置。
- 按当前任务身份、完成状态和 PDF 检查判断成功；NX 2506 启动器返回 0 不能掩盖 Worker 失败。历史探针返回 37 而启动器返回 0 的记录保留。
- 保留串行导出、有效图纸页筛选、默认跳过、安全覆盖、取消及失败后继续，不保存源 PRT。

## 支持范围

Windows 11 x64。仅接受以下本机实际验证的三组件文件版本（NXOpen / NXOpen.UF / NXOpen.Utilities）：

- NX 10：10.0.0.24 / 10.0.0.23 / 4.0.0.0。
- NX 2506：2506.0.0.0 / 2506.1700.0.0 / 2506.0.0.0。

未知补丁及混搭组件拒绝运行。支持两代不表示 NX 10 可以读取 NX 2506 保存的 PRT。

## 下载与升级

从 [GitHub Release](https://github.com/GUZHUYAXIAN/nx-pdf-sample/releases/tag/v2.0.1) 下载 `NX-Drawing-PDF-Exporter-v2.0.1-win-x64.zip`，核对 SHA256SUMS.txt 后解压至新目录。保留 `worker/nx10` 与 `worker/nx2506`，不要混入旧版 Worker。

GUI 自带现代 .NET 运行时；Worker 使用 Windows 已有的 .NET Framework 4.8 和用户合法安装的 NX。包内不含 Siemens DLL、私有 PRT/PDF、截图、日志或许可证凭据。

首次升级建议使用制图与模型副本、新输出目录及默认跳过策略，检查实际 PDF 后再投入日常使用。跨版本旧图纸仍应核对标注。
