## 3. 页面布局与滚动

主窗口从上到下：

1. 固定菜单栏。
2. 主体滚动视口：设置折叠标题与摘要、设置内容、预检查工具栏、预检查表格、预检查下方高度拖动条、运行结果标题/汇总/详情、结果高度拖动条、结果表格。
3. 固定开始/取消、当前状态与进度栏。

右侧只设一个主体纵向滚动入口。设置内容按自然高度参与主体排列，设置与预检查之间没有独立视口、强制分隔或可拖动边界。输出组多时由主体滚动承接，不另给设置套滚动框。折叠标题和摘要保留，手动文件清单原有自动/手动展开规则保留。

三个表格（手动清单、预检查、结果）可有内部滚动，但只有实际内容溢出可视区域时才显示对应方向滚动条；空表或少量行能完整显示时不能保留无效纵向滑块。溢出判断使用实际表头、换行后行高、可用尺寸与横向滚动条占用，不能用固定行数估算。需要时水平滚动独立出现，长文件名不退回省略号。

滚轮归属由指针所在位置决定：

- 在表格上且该方向还能滚：只滚该表格。
- 表格无需滚动，或已经到该方向边界：同方向交给主体。
- 标题、工具栏、普通输入框与空白区：滚主体。打开的下拉弹层、正在拖动的滑杆等保留自身明确操作，不误传主体。
- 单个滚轮事件不得造成内外双重滚动；高精度滚轮的不足一格增量需累计。若内部滚动消耗后才到边界，本次已消费，后续事件转主体。
- 不靠改变选中行或修改正在编辑的版次实现滚动。不用会把事件绕回自身的递归消息转发。
- 主体本身也仅在溢出时出现滚动条；出现/消失后的宽度、换行和溢出结果必须收敛，不能来回闪烁。

### 3.1 两处独立高度控制

- 预检查的拖动条在其表格下方；拖向下增加预检查高度。
- 结果的拖动条位于运行结果工具栏下方、列标题上方；作为高度调节手柄，向上拖增加结果高度，向下拖缩小。只改变结果的高度，不借用预检查高度；主体总高度随之变化。手柄锚定在标题下，按相对拖动量调节，避免为了移动边界反向挤占前一区。
- 提供上下调整光标、可见抓手、悬停说明和键盘调整；鼠标捕获期间离开控件也能继续拖动，结束或失去捕获后恢复。
- 最小高度至少容纳表头和常规数据行，拖动不能隐藏固定操作区。恢复默认布局同时恢复两者。
- 以 96 DPI 逻辑尺寸持久化两个高度；切换 DPI 不反复累计缩放。设计者初值：预检查 280 DIP、结果 320 DIP，保存值范围 120–2000 DIP；实际最小值还需满足当前字号的表头/常规行。手动清单保留约 132 DIP 的独立正常高度，不增加本轮未要求的第三个拖动手柄。
- 折叠、布局、主题、字号、语言变化不得丢失已选行、文件清单、目录映射、筛选、未确认编辑和手动版次。能保持原可见位置时保持；内容缩短时只把滚动位置限制到合法范围。

## 4. 图片皮肤的合成与交互

删除主界面右侧独立 artwork PictureBox、预留列宽及其单独缩放/生成任务；设置重新使用完整可用宽度。外观对话框可保留缩略预览。

应用客户区只有一张连续底图，覆盖菜单、主体各区和底部操作区，固定在窗口坐标中。各控件绘制自身对应的同一片图像；整体滚动、内部滚动不能让照片随行移动、重复铺图或产生接缝。缩放窗口、跨 DPI、拖动区域高度时坐标仍一致。人物位置由图片缩放、水平/垂直位置控制，不依赖独立照片栏。

主窗口各层：

1. 图片经缩放/裁切、图片强度、模糊、雾化和渐变得到底图。
2. 面板、工具栏、表头、按钮和输入区叠加主题色材料；输入编辑区可稍厚。
3. 目录组整行半透明底色、选中/悬停/焦点/状态反馈。
4. 不透明、清晰的文字和图标。

表格单元格、表头、空白区域、边界、选择、多选、焦点、错误提示、编辑覆盖控件和实际滚动条都属于交付范围。不能留下大片原生白底或用画出来的假滚动条冒充可操作控件。沿用标准 DataGridView 的数据、编辑、选择与键盘能力；确实需要替换的滚动实现必须保持键盘、滚轮、拖动、分页和可访问名称。

目录底色继续整行呈现，PRT 行与对应输出目录使用同组色相、色层强度和标识。照片背后像素不同可以导致合成结果不同，但不能分配不同组色。选中行也保留 A/B 等文字标识或色条。目录颜色不承载成功/失败语义。

产品自己的菜单、工具提示、详情、版次输入和外观对话框保持同套材料和文字规范；新对话框有自己的固定底图坐标，不截取另一窗口的屏幕内容。系统文件选择器和 Windows 非客户区标题栏沿用系统行为，不注入或改系统设置。系统高对比模式优先使用系统颜色并停用图片纹理，退出后恢复用户皮肤。

## 5. 离线分析、高对比与自动遮罩

预置照片和用户新导入照片使用同一套规则。像素分析仅在本机进行，不调用模型、联网服务或运行时下载组件。提取主色调可以缩略采样，最终可读性必须依据实际显示的合成背景。

### 5.1 字色与验证

- 提取主色、亮暗分布，生成多个与图片协调且明暗足够分离的候选。保留深/浅中性色作为兜底，但不把自动配色实现成永远白字或仅黑白二选一。
- 使用 sRGB 相对亮度计算对比度，不用 RGB 简单平均、色相距离或 GetBrightness 代替。普通可读文字最低 4.5:1；文件名、路径、正文和状态优先争取 7:1。阈值不四舍五入。
- 检查图片效果、面板遮罩、目录组色、选中/悬停底色合成后的背景，覆盖正文、说明、输入、提示和状态。统计“平均对比度达标”不能掩盖最差位置。
- 主色调采样不足以证明全部像素达标。对最终缓存图使用区域像素/保守亮度边界验证；若无法可靠评估，使用已验证材料回退，不能把采样分位数称为全区域保证。
- 文字角色形成稳定色板。滚动不改变字色，不能每行/每像素换色；尺寸变化优先用材料保护维持原字色。更换照片、调效果或主动选配色时重新计算，异步旧结果不得覆盖新选择。
- 成功/警告/失败保留语义、中文标签及图标；可改变同一色相族的明暗，必要时用状态底层保护，不把红色错误自适应成绿色成功。选中文字单独求对比。

### 5.2 用户已接受的遮罩保护

若某区域过亮、过暗或纹理复杂，系统可以自动调整该面板遮罩深浅或不透明度，保持稳定字色。优先采用满足阈值的最小额外遮罩；不能为了省事把所有图片主题变成完全不透明面板。

“用户请求的遮罩强度”和“本次显示的有效强度”分开：

- 手动滑杆值原样保存，不被自动保护改写。
- 自动保护是运行时推导，必要时在外观面板给简短说明，例如“已为文字清晰度增强局部遮罩”；不逐行弹窗。
- 先争取 7:1；达不到时必须达到 4.5:1。对极端图片允许受影响的局部材料趋近实色，正常图像仍保留可见背景。
- 用户手动指定文字色仍需要对比验证，并由保护材料补足；“恢复自动”立即回到自动配色。手动颜色不等于关闭可读性保护。
- 滚动期间避免材料强度闪变：对可能覆盖的背景范围做保守缓存，或保持已验证的稳定材料；不得每滚一格重选全套颜色。

- https://www.w3.org/WAI/WCAG22/Understanding/contrast-enhanced.html

## 6. 外观参数、配置和性能

外观面板以中文/English 对应显示：

- 图片强度 0–100：0 隐藏图片，100 完整图片层。
- 面板遮罩强度 0–100：0 最弱人工遮罩，100 实色；自动保护可以在其上增加有效遮罩。
- 模糊、雾化、渐变强度各 0–100，0 无该效果。仅作用背景，不模糊文字、边框、图标。
- 渐变方向至少支持左到右、右到左、上到下、下到上。
- 保留缩放、水平/垂直位置。照片模式默认提供深色融合，也可选浅色融合；这是材料倾向，最终文字由对比计算决定。
- 自动高对比配色默认开启；提供手动字色微调与恢复自动。

继续实时预览、应用、取消、恢复当前预设。取消/关闭恢复进入对话框前的完整外观，包括导入图引用、配色、自动保护状态和缓存代次；不能被未完成的异步回调再改回预览。每个预设独立保存参数；本轮仍沿用现有一个导入图槽位，不新增图库管理。恢复当前皮肤不改业务数据。

升级独立 ui-settings.json 到 schema 2，兼容读 schema 1。迁移保留语言、主题、导入图引用、字号、窗口与列宽、所有既有主题参数；旧 SplitterRatio 不能表示两个独立高度，首次迁移采用新的两个默认高度。损坏字段局部恢复并一次提示，不因新增字段缺失而丢掉整套有效旧设置。NX 的 settings.json 不变。

只处理原图的应用自有副本，不修改原图。沿用 PNG/JPEG、32 MiB 和 4096 万像素上限，EXIF 方向、透明 PNG 预合成、损坏图片都应覆盖。新图片处理失败时保留当前有效外观。

主色提取、背景效果和材料验证在可取消/代次可淘汰的后台工作中完成，UI 线程只应用最新完整快照。重绘复用不可变缓存，不重新读图/分析/模糊；滚动不启动全图算法。位图所有权明确，换主题、取消和关窗释放资源，避免重复事件订阅。保持现有图像资源上限，不能生成每行一张长期缓存位图。

## 7. 实施与验证

用户继续负责 GUI 操作、DPI 切换/截图和物理断网；助手先完成代码/自动检查/本地候选并提供可执行清单，核对用户返回的证据。等待用户 GUI 反馈不妨碍完成独立的代码和自动化工作，但视觉未验时必须标“候选，待视觉验收”，不能宣称 B 已通过。

必须覆盖：

- 设置展开/折叠、0/少量/大量行、多输出组、长中文名换行、两个高度手柄和内外边界滚动。
- 未提交版次、无效版次、多选、筛选、取消/运行期间切换外观、焦点/键盘。
- 四张预置图、纯白/纯黑/黑白混合/高纹理/透明 PNG/横竖构图；自建合成夹具不含私有样例。

- 100/125/150% DPI 必须列入验收；200% 和跨屏 DPI 作为扩展项，最小窗口与最大化都需检查。
- 连续滚动、快速调滑杆、预览后取消、关闭/重开，图片无错位、白底闪现或旧任务覆盖。

## 8. 决定来源

用户决定：整体滚动；设置保持折叠且连接预检查；预检查底部及结果标题下方两处调高；内部条仅溢出出现；删除右侧照片；采用 B；图片融合；离线自动高对比字体；接受必要时调整遮罩。

设计者补齐：具体滚轮边界转交、固定底图坐标、菜单/操作固定、两个高度默认值与顶端手柄方向、schema 2 迁移、保护不改写滑杆、自动色稳定、语义色保护、极端图片局部材料回退和验证矩阵。这些用于落实已确认目标，可由用户纠正；不是用户逐项指定的色值或内部算法。
