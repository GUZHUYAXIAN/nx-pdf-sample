# 同事 Codex 验证提示词：NX Drawing PDF Exporter V2 候选版

你的任务是验证一份已经收到的 NX Drawing PDF Exporter V2 候选包，重点证明它能
在本机自动发现非开发机固定路径下的 Siemens NX 10.0.0.24，并安全完成一次真实
PDF 导出。你只负责只读命令检查、哈希、日志和结构化结果分析；所有鼠标、键盘、
窗口、NX/程序 GUI、Windows 显示缩放、断网和截图操作必须由我本人完成。

开始时一次只询问一个必要输入，依次取得：

1. 收到的候选 ZIP 或候选文件夹绝对路径；
2. 随包 SHA-256 manifest 的绝对路径；
3. 用于验证的制图 PRT 绝对路径；
4. 与该图纸关联的模型 PRT 绝对路径。

不要在回复中重复私人文件名、完整业务目录或哈希值；用“候选包”“制图 PRT”
“关联模型”和前后是否一致来报告。原始值只保存在本机临时验证目录，不上传、
不提交 Git、不发送到外部服务。

严格边界：

- 不安装、下载、升级或修复任何软件、SDK、包或运行库。
- 不修改 NX 安装目录、注册表、PATH、系统/用户环境变量、服务、网络配置或
  `ugii_env.dat`。
- 不保存、重命名、移动、删除或覆盖两个 PRT；不调用 NX 保存接口。
- 不使用管理员权限，不关闭安全软件，不访问无关文件或注册表位置。
- 不推送、不发布、不创建外部 Issue，不上传样例、日志、截图或图纸内容。
- 不自行操作 GUI；先给我操作步骤、预期结果、截图要求和停止条件，然后等待。

只读检查顺序：

1. 计算候选包/manifest 的 SHA-256 并按 manifest 逐文件复验；不匹配就停止。
   候选版本由项目的最新 V2 验证状态确认，不使用已被替换的旧 ZIP。保留（若存在）
   `%LocalAppData%\NxDrawingPdfExporter\diagnostics\run.log` 中本次检测对应的
   脱敏错误代码、来源和异常类型；没有该日志不代表已通过全部检测。
2. 确认 Windows 为 x64，并读取以下有界 NX 信号，不输出无关值：
   - 当前进程 `UGII_BASE_DIR`、`UGII_ROOT_DIR`；
   - 64/32 位 `HKLM\SOFTWARE\Unigraphics Solutions\NX\*` 下的
     `UGII_BASE_DIR`；
   - 64/32 位 Windows Uninstall 项中 DisplayName 为 Siemens NX 10.0 的
     `InstallLocation`。
3. 对候选根目录只读确认 `UGII\run_managed.exe` 与
   `UGII\managed\NXOpen.dll` 存在，并读取 NXOpen.dll 文件版本。必须精确等于
   `10.0.0.24`；否则停止，不尝试兼容其他版本。
4. 将候选包解压到本机临时的新目录；不得覆盖旧版本或放入 NX 安装目录。
5. 分别计算制图 PRT 和关联模型的运行前 SHA-256，并保存到本机临时报告。

然后按随包的 `docs/verification/v2/colleague-manual-checklist.md` 给我 GUI 操作清单：
启动 `NX图纸批量导出工具.exe`，等待自动检测，截图完整 NX 环境区，确认显示的是
本机实际安装且没有先点“手动选择”；选择受控输入与输出，执行预检查和一次导出，
截图完整结果区。显示缩放必须逐项验证 100%、125% 和 150%，每一档都要求截图中
同时包含 Windows 当前缩放证明和程序完整窗口，并覆盖 NX 已就绪、两种输入模式、
长输出路径、预检查、运行中禁用状态和最终结果。每次切换缩放后，如 Windows 提示
注销或重启，应由我本人完成后再继续。程序自动发现失败时立即记录状态和日志，
此时自动发现判定失败；之后可以单独测试“手动选择 NX 目录”兜底，但不得把手动
成功写成自动发现成功。

联网成功完成导出后，再由我本人按清单执行一次物理断网验证：关闭 Wi-Fi/拔掉网线，
确认系统已无网络连接，再启动同一候选包完成自动检测、预检查和导出。需要截取断网
状态与完整程序窗口同框的启动后画面，以及最终结果画面。测试结束后由我本人恢复
网络；你不得修改网络配置或代替我操作。

导出结束后，你再执行只读验证：

- 解析该次 `result.json`，确认 RunId、逐文件终态和无 FatalError；
- 检查正式 PDF 存在、非零、具有 `%PDF-` 文件头，并使用候选程序自身的证据或
  已存在的本机工具确认页数；不得安装 PDF 工具；
- 计算两个 PRT 的运行后 SHA-256，并逐项与运行前值比较；
- 检查运行日志中使用的 `run_managed.exe` 属于本机发现出的 NX 根目录；
- 检查没有开发机固定路径、联网、下载、更新或认证提示；
- 只向我报告哈希“相等/不相等”，不要展示原始哈希。

任一情况下立即停止：候选包哈希不符、NXOpen 版本不符、自动发现指向错误目录、
缺少 Worker、出现 NX 保存提示、源文件哈希变化、正式 PDF 残缺、出现联网行为、
需要安装工具或需要修改系统/NX。停止时保留本次临时目录和日志，不重复运行，给出
脱敏的失败阶段、错误类型和下一步需要项目开发者判断的事实。

最终报告必须区分：自动发现、手动兜底、Worker 启动、导出结果、PDF 检查、源文件
完整性。只有全部必需项通过，才写“本机非默认路径验证通过”；否则明确写“V2
候选验证未通过/未完成”。
