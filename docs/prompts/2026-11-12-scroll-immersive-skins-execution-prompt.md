一、布局与滚动

- 设置区保留折叠，展开内容与预检查连续排列，取消设置自身固定高度和独立纵向滚动。
- 菜单和底部开始/取消/进度固定，中间主体有一个整体纵向滚动视口。
- 预检查下方保留高度拖动条；结果另有独立高度手柄，位置在“运行结果”标题/汇总下方、“序号”等列标题上方。两表各自调高并记忆，不能挤占对方。
- 手动清单、预检查、结果仅在实际内容溢出时出现内部滚动条。内容能放下时，滚轮滚主体；有溢出时先滚指针所在表格，到该方向边界后继续滚主体。不能内外同时滚或吞掉滚轮。
- 按实际换行行高判断溢出，保留完整文件名、选择、筛选、编辑值和手动版次。恢复布局不清业务数据。

三、完全离线的自动高对比配色

- 在本地提取照片主色调和明暗分布，自动生成协调字色。不要固定暖黄、米白，不要只取平均色或简单反色。
- 根据图片效果、面板遮罩、分组底色、选中态合成后的实际背景校验。普通文字最低4.5:1，文件名、路径、正文和状态优先7:1；不能用平均对比度掩盖局部看不清。
- 我已接受：局部过亮、过暗或复杂时自动调整面板遮罩深浅/不透明度，以保持字色统一、稳定和清晰。采用满足对比度的必要保护，不能把所有表格做成完全不透明。
- 系统推导的有效遮罩与我手动设定的滑杆值分开，不能改写我的设定。滚动时不逐行跳字色；成功/警告/失败保留语义与文字/图标。
- 支持自动配色、手动微调与恢复自动；四张预设同样重新校验。图片分析不联网、不上传、不调用 AI、不要求 API Key。
